# IELTS PQ Marker App

Native Kotlin app. Offline PQ drill plus Meta API writing and speaking marks.

## Status

Scaffold only. Full Gradle build is blocked until an Android SDK with
platform 34 is present. See Task0 host check notes from the setup worker.

## Build (needs SDK)

Requires JDK 17, Android SDK platform 34, and a Gradle wrapper.
Then run: ./gradlew :app:assembleDebug
